# /seminar-deep

**Not** the 40×/year command. Refuse to run if leftover is not `structured` on the pocket, or if the user is still in the hallway dump.

## When it is legal

| Path | When |
|---|---|
| COLLAB | Before the talk, leftover `structured`, user is chasing a collab |
| INDEPENDENT | **After** `/seminar-after` labels INDEPENDENT. Friday job. Required **before** writing a results file |

If neither: stop. Point them at `/seminar`.

## Dual-use

Same refuse list as `/seminar`. Dual-use-adjacent → refuse the method; do not write a recipe.

## Append to the **same** pocket file

A section `## Deep` (not a new file, not INDEX). Include:

1. **Data card** — each field `{value | UNKNOWN}` + locator (slide/URL). Fields: organism, modality, n / unit, labels, split keys if any, access (`public` / `ask` / `none`). **No invented numbers.**
2. **Killed candidate** — at least one written reject (thin n, leakage, already done, model-name-as-idea, dual-use).
3. **If a method is licensed** (only if leftover + identification allow it):
   - method **class** (operator on their design; model name is not the idea)
   - dumb baseline + biological metric
   - week-1 **numeric** kill (what number, on whose already-collected data, fails the story)
   - ≤2 **verified** papers that scoop or kill (API/DOI check). Not a survey.
4. **COLLAB:** 5-line ask (named asset + we-bring). **INDEPENDENT:** the results path that would kill **this** leftover, not a recycled `exp00`.

Kill of a method = leftover explained by batch, leakage, or re-description — not “AUROC too low.”

## Refuse

Deep as a writeup of the pocket. Deep before an INDEPENDENT **run** without after-log. Deep on a thin card. Fourth command names.
